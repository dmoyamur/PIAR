# PIAR
PIAR es el Plan Individualizado de Ajustes Razonables, diseñado para crear inclusión a niños y jóvenes con algún tipo de discapacidad dentro de sus aulas escolares.
Este proyecto quiere facilitar la labor de una maestra de educación especial para el control y recopilación de historia médica, escolar y familiar de los alumnos a su cargo.

Par la ejecución de éste proyecto se puede realizar usando:
start
node app.js
